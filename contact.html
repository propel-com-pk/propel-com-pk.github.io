FAQ

Questions we hear before a project starts.

Do you work on existing products?

Yes. We can improve an interface, clean up a release, fix problems in production, or continue development on an existing codebase.

Can you start with a small scope?

That is often the best approach. A small, well-defined first step makes the rest of the project easier to plan.

What happens after I send the form?

You will get a short reply with the next practical step, usually a brief call or a request for more detail if the scope is still open.
